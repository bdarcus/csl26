Global options

Global options apply across citation and bibliography rendering unless a section or component overrides them.

options:
  processing: author-date
  contributors: apa
  dates: long
Option familyControls
processingauthor-date, numeric, note, or label behavior
contributorsname order, initials, conjunctions, shortening
dateslong, short, numeric, or ISO date rendering
titlestitle casing and title form behavior

Range and number formatting

options.range-format controls how a closed numeric range abbreviates its second number (112–118 → 112–18). It's the style-wide default for the bibliography page count and, unless a locator kind opts out, every citation locator kind too — a page locator and a chapter locator both inherit it.

options:
  range-format: chicago16
  locators:
    kinds:
      chapter:
        range-format: expanded   # opt this one kind out
Value112–118 becomes
expanded (default)112–118
minimal112–8
minimal-two112–18
chicago / chicago16112–18 (Chicago Manual of Style rules)

Citation-number ranges ([1–3] in a numeric style) and compound sub-entry / same-author-suffix letter ranges (1a–c, 2020a–c) don't inherit options.range-format — they're list positions and disambiguation letters, not prose page numbers, so citeproc-js and Citum both treat them as their own kind of thing. Citation numbers default to expanded independently; opt them into abbreviation with their own key:

options:
  range-format: chicago
  citation-numbers:
    range-format: expanded   # stays its own default

The join character is separate from the abbreviation rule. options.range-delimiter overrides the locale delimiter for page and locator ranges. American Medical Association, for example, uses a hyphen. Citation-number, compound sub-label, and same-author suffix ranges use options.identifier-range-delimiter. Its default is an en dash and remains independent of the page/locator delimiter.

options:
  range-delimiter: "-"                 # pages and locators
  identifier-range-delimiter: "~"      # [1~3], 1a~c, 2020a~c

Migration note: the former top-level keys page-range-format and page-range-delimiter are now range-format and range-delimiter. Update authored styles before loading them with this schema version.

Component rendering options

Use component options for punctuation, wrapping, and emphasis.

- title: parent-serial
  prefix: ". "
  emph: true

- number: pages
  prefix: ", "
  label-form: short
⚠️
Do not hardcode localized labels Avoid prefix: "pp. " or prefix: "In: ". Use term components or label options so locale files own language-specific text.

Options inheritance

More local options override broader options:

  1. component-level options
  2. citation or bibliography section options
  3. global options
options:
  contributors: apa

citation:
  options:
    contributors:
      shorten: { min: 3, use-first: 1 }

Bibliography sort and groups

bibliography:
  sort: author-date-title
  groups:
    - id: primary
      heading:
        localized:
          en-US: "Primary Sources"
      selector:
        type: legal-case

Document-level abbreviation maps

Abbreviation maps belong to the document input, not the style. They replace full rendered strings after value extraction and before output assembly.

abbreviation-map:
  Estates Gazette: EG
  "Lloyd's Law Reports": "Lloyd's Rep"
  "World Health Organization": WHO
